# WTF 1.0.1

WTF 1.0.1 consolidates the workspace improvements and restores shared lifecycle
policy across repositories.

- Declarative lifecycle hooks inherit from ancestor `.wtf/config.toml` files,
  outermost first. Each hook package keeps its own imports. Shared policies such
  as copying ignored `.env` files now run during `wtf new`.
- `wtf remove` and `wtf rm` work from parent directories with the same repository
  scope as switch, without `--global`. The picker labels repositories and supports
  searching their names. Ambiguous direct names are rejected before removal.
  Repository hooks, identity checks, ownership checks, and protection for late
  source edits remain enforced.
- Workspace pickers support fuzzy search while preserving selections and review.
- Setup installs a self-contained agent guide, refreshes unchanged generated
  guides, and preserves local edits. New workspaces inherit independent guides.
- Port-claim documentation and regression coverage clarify repository ownership,
  concurrent claims, retries, and cleanup.

Configuration and JSON envelope versions remain `1`. Supported release platforms
remain Linux amd64, arm64, arm (GOARM=7), and 386.
